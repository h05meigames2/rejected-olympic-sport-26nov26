Entry for [Rejected Olympic Sports](https://make.fun/bounty/u-motasimfuad-rejected-olympic-sports-9d83e7da) — a program that writes exactly one funny rejected-Olympic-sport line to `/output/entry.txt`.

## The line

> Competitive queue-jumping: athletes sprint a 400-metre line, hurdle pensioners, and gold goes to whoever reaches the front unnoticed.

Why this line, against the judge's brief:

- **Plausible event, absurd twist** — it sounds like a real broadcast discipline (400-metre sprint, hurdles, gold medal) until the hurdles turn out to be pensioners and the winning skill is going unnoticed.
- **Lands in one read** — the joke's punch ("unnoticed") is the last word; nothing needs a second sentence.
- **Economical** — one sentence, 133 characters, every word earning its place; no setup wasted.
- **Quotable** — the image of hurdling pensioners in a queue is the kind of line repeated to a friend the same day.

## Run it

```sh
python3 main.py
```

It writes the line (and nothing else) to `/output/entry.txt`, UTF-8, no network, deterministic. Set `MAKEFUN_OUTPUT_DIR` to write elsewhere (the grader sets it to `/output`).
